Terbitkan Perubahan

Pilih salah satu cara. Setelah terbit, tunggu 1–2 menit lalu tokomu memakai pengaturan baru.

Cara mudah: salin lalu tempel

  1. Tekan tombol Salin pengaturan di bawah.
  2. Buka repo webmu di GitHub, tekan tombol titik (.), lalu klik file config.json.
  3. Tekan Ctrl+A, lalu Ctrl+V (hapus isi lama, tempel yang baru).
  4. Klik ikon cabang di kiri, tulis pesan, lalu Commit & Push.

Otomatis: langsung terbit dari panel ini

Kamu hanya perlu mengisi sekali. Kunci akses (token) tersimpan di perangkat ini saja, tidak masuk ke GitHub dan tidak ke web toko.

Cara membuat token: GitHub → foto profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Pilih Only select repositories (repo tokomu saja), lalu di Permissions → Contents pilih Read and write.
