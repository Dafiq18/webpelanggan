‹Panduan Pemilik Toko

Halaman ini untuk kamu (pemilik toko), bukan untuk pembeli. Ketuk judul di bawah untuk membuka langkah-langkahnya.

☀️ Rutinitas harian (5 menit)
  1. Buka Pesanan dan masuk dengan akun admin.
  2. Lihat pesanan berstatus Baru. Tekan 💬 Chat pelanggan untuk menghubungi lewat WhatsApp dan mengonfirmasi.
  3. Setelah pelanggan membayar dan kamu cek uangnya masuk, ubah status ke Diproses.
  4. Siapkan parfum, tekan 🖨️ Cetak label, tempel label di paket. Ubah status ke Dikirim saat paket diserahkan ke kurir.
  5. Setelah paket diterima (atau sudah jelas selesai), ubah ke Selesai. Stok parfum berkurang otomatis saat status Selesai.
  6. Buka Stok. Tekan 📋 Salin daftar belanja kalau ada parfum yang habis atau menipis.
Pelanggan bisa melihat perkembangan pesanannya sendiri di menu 📦 Pesanan Saya di toko. Statusnya ikut berubah saat kamu mengubahnya di halaman Pesanan.
📦 Status pesanan, artinya apa?
StatusArtinya
BaruPesanan baru masuk, belum kamu konfirmasi.
DiprosesSudah dibayar dan sedang kamu siapkan.
DikirimPaket sudah diserahkan ke kurir.
SelesaiPesanan tuntas. Stok parfum berkurang otomatis (sekali per pesanan).
BatalDibatalkan. Stok tidak berkurang.
Pembayaran masih manual: pelanggan transfer lalu kirim bukti lewat WhatsApp. Selalu cek uang benar-benar masuk sebelum mengubah ke Diproses.

Tanda ⚠️ di pesanan

Kalau ada ⚠️ "total tidak sesuai", artinya harga di pesanan berbeda dengan harga tokomu. Cek dulu sebelum memproses, dan minta pelanggan membayar sesuai harga yang benar.

🧴 Mengatur stok (dalam ML)
  1. Buka Stok dan masuk.
  2. Ketik jumlah ML di kotak parfum. Contoh: punya 1 liter → 1000. Pakai tombol +100 / +500 / +1000 setelah belanja.
  3. Tekan Simpan perubahan di bagian bawah.
  • Kotak kosong = parfum tidak dihitung stoknya (selalu tersedia).
  • Di bawah 30 ML = tampil STOK HABIS di toko. Di bawah 300 ML = tanda Sisa … ml.
  • Untuk mengisi banyak parfum sekaligus, pakai ⚙️ Atur semua yang tampil.
Stok baru berkurang saat pesanan ditandai Selesai, jadi dua pembeli masih bisa memesan parfum terakhir yang sama sebelum kamu menandainya. Pantau stok parfum yang laris.
🏷️ Harga, produk baru, dan promo
  1. Buka Produk.
  2. Cari parfum, tekan Ubah untuk mengganti harga, foto, atau menandainya habis. Untuk parfum baru, pakai tombol tambah produk di halaman itu.
  3. Tekan Terbitkan. Tunggu 1–2 menit, lalu perubahan muncul di toko.

Parfum baru otomatis tampil di paling atas katalog.

Foto produk

  • Buka Cek Foto dan tekan Mulai periksa (1–3 menit) untuk mencari foto yang rusak.
  • Gunakan foto milikmu sendiri (unggah ke GitHub). Foto dari situs lain bisa hilang sewaktu-waktu dan bisa bermasalah soal hak cipta.
🏪 Info toko, bayar, dan testimoni
  • Alamat, jam buka, kebijakan retur: ubah isi di file info.html (bagian var TOKO).
  • Rekening / DANA / QRIS: ubah di index.html, bagian KODE BAYAR (daftar METODE).
  • Testimoni pelanggan: isi file testimoni.json. Pakai testimoni asli dan seizin pelanggan.
  • Logo / ikon: file logo.png (persegi, sebaiknya 512×512).

Cara mengubah file: buka GitHub → klik file → ikon pensil → ubah → Commit changes → tunggu 1–2 menit → tekan Ctrl+Shift+R di toko.

🆘 Kalau ada masalah
MasalahYang dilakukan
Lupa sandi admin / "too-many-requests"Tunggu 15–30 menit. Atur ulang di Firebase → Authentication → Users → ⋮ → Reset password.
Perubahan di GitHub belum terlihatTunggu 1–2 menit, lalu tekan Ctrl+Shift+R. Kalau di HP, tutup lalu buka lagi browsernya.
Muncul "File could not be edited" saat CommitSalin dulu kode yang kamu ubah ke catatan, muat ulang halaman GitHub, lalu ulangi.
Halaman admin menampilkan "Gagal memuat"Periksa internet, lalu muat ulang. Pastikan aturan database di Firebase sudah di-Publish.
Pesanan tidak muncul di halaman PesananMuat ulang. Cek pesan WhatsApp dari pelanggan karena pesanan tetap sampai ke WhatsApp.
Parfum tidak bisa dipesanCek di Stok: mungkin stoknya di bawah 30 ML atau ditandai habis di Produk.
🔐 Keamanan, singkat saja
  • Jangan membagikan sandi admin. Kalau memberi akses ke karyawan, buatkan akun terpisah di Firebase.
  • Token GitHub (untuk menerbitkan produk) hanya disimpan di browser perangkatmu. Jangan menulisnya di GitHub atau mengirimnya ke siapa pun.
  • Data pesanan hanya bisa dibaca akun admin. Halaman admin yang terlihat publik tidak bisa mengubah apa pun tanpa login atau token.
  • Data pelanggan (nama, alamat, nomor WA) hanya dipakai untuk memproses pesanan. Hapus bila pelanggan memintanya.
